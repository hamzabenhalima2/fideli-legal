Questions fréquentes

Comment créer un compte ?

Ouvrez l'app, choisissez « Se connecter — Client », saisissez votre numéro de téléphone marocain, votre prénom et un code à 4 chiffres. Aucun SMS n'est envoyé : le code est celui que vous choisissez.

J'ai oublié mon code

Écrivez-nous à l'adresse ci-dessus depuis n'importe quelle boîte mail, en précisant votre numéro. Nous vérifions votre identité et réinitialisons l'accès.

Comment gagner des tampons ?

Chez un commerce partenaire, montrez le QR code de votre carte : le commerçant ajoute un tampon. Chaque commerce a sa propre carte et sa propre récompense. Quand la carte est pleine, la récompense vous est remise sur place par le commerce.

Mes tampons d'un commerce marchent-ils ailleurs ?

Non. Les tampons restent liés au commerce qui les a donnés. Fideli centralise vos cartes, il ne mélange pas les points.

Supprimer mon compte

Dans l'app : Profil → Supprimer mon compte. La suppression est immédiate : votre identifiant de connexion et votre prénom sont effacés et vous êtes déconnecté. Les tampons déjà accordés par les commerces restent dans leur registre, mais ne sont plus rattachés à votre nom. Vous pouvez recréer un compte avec le même numéro plus tard.

Vous pouvez aussi écrire « Suppression de compte » à hamza.benhalima2@hotmail.com avec votre numéro. Voir la politique de confidentialité.

Je suis commerçant, comment rejoindre Fideli ?

Écrivez-nous : nous créons votre carte (objectif de tampons, récompense, couleur) et vous transmettons votre code d'accès commerçant.
